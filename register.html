Entra en GitHub (otra pestaña)

  1. Cuando ya hayas entrado, pulsa Registrar GitHub App Morada-nube.
  2. GitHub muestra un formulario ya relleno. Pulsa Create GitHub App. No cierres esa pantalla.
  3. Instálala en un solo repositorio. El watcher abre el PR.

Si GitHub dice que el nombre está ocupado, la App ya existe (es privada: no sale en el directorio). Ábrela en GitHub → Settings → GitHub Apps, instálala en un repo, genera un Client Secret y una PEM, y envíalos aquí. El código de conversión caduca.
