Entra en GitHub en este navegador con tu usuario. Si GitHub pide login, entra y vuelve a pulsar el botón.

  1. Pulsa Registrar GitHub App Morada-hogar.
  2. GitHub muestra un formulario ya relleno. Pulsa Create GitHub App. No cierres esa pantalla.
  3. Instálala en un solo repositorio. El watcher abre el PR.

Si el repo vive en una organización, regístrala ahí. Una App privada solo se instala en la cuenta que la posee.


Esta página no pasa por Cloudflare. Si el botón no responde, entra en GitHub y pulsa otra vez.
